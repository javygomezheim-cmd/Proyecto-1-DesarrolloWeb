# Plataforma de gestión de actividades académicas

## Integrantes
Javier Gómez - Tomas Contreras

## Descripción

Este proyecto consiste en una plataforma web para gestionar actividades académicas de estudiantes.

La aplicación permite visualizar las tareas, organizarlas según su asignatura y estado, registrar nuevas actividades y realizar un seguimiento del progreso académico.

## Funcionalidades

- Visualización de tareas académicas.
- Registro de nuevas tareas.
- Edición de tareas.
- Eliminación de tareas.
- Marcar tareas como completadas.
- Historial de tareas completadas.
- Filtro de tareas por asignatura y estado.
- Registro y eliminación de asignaturas.
- Indicador de progreso académico.
- Identificación visual de tareas vencidas, próximas y con entrega para el día actual.
- Diseño adaptable a distintos tamaños de pantalla.
